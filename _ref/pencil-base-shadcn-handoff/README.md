# DATAMIX shadcn Handoff

This folder contains a practical implementation packet for the redesigned headless CMS admin.

Use `DatamixDashboard.tsx` as the reference implementation and `IMPLEMENTATION_BRIEF.md` as the LLM handoff instructions.

Copy `globals.css` tokens into the target app's global stylesheet, adapting only if the project already has a shadcn theme file.

The `assets/` folder contains exported PNG references from the final Pencil design.
